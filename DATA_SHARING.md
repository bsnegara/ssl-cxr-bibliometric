# Data sharing statement

## Shared

- Scopus EIDs and DOIs of all 207 retrieved records, with the author's screening decision, exclusion code, and task label.
- Blinded validation samples (three rounds) with both decisions per record.
- Query strings, lens strings, gold-set DOIs.
- Thesauri used in VOSviewer.
- Notebooks and scripts.
- Aggregated results (counts, indicators, cluster memberships by EID or by label).
- The author's extraction coding for 30 documents.

## Not shared

- Raw Scopus exports (`scopus_S1.csv`, `.ris`, `.bib`), cleaned corpus files (`corpus_S1_clean.csv`, `corpus_2022_2026.csv`, `M.rds`, `raw.rds`), or any file containing abstracts, author keywords, Keywords Plus, or cited-reference lists. These are subject to Elsevier's Scopus license.

## Before uploading a notebook

Clear all cell outputs (Edit > Clear all outputs in Colab) if they print abstracts, titles in bulk, or reference strings.
